Aplicar masivamente

Pisa dia de pago / crear factura / dias de gracia de todos los clientes a la vez (incluye los que ya tenian un override individual). Util para alinear a todos de una sola vez -- deja un campo vacio para no tocarlo.

Facturacion (default)

Valores por defecto para todo cliente que no tenga su propio override (en "Configuracion" del perfil de cliente). "Dias de gracia" todavia no afecta el estado "vencido" (solo se guarda). "Crear factura" SI genera la boleta del mes actual por adelantado, pero solo para clientes de cobro fijo (percentil/variable siempre espera a que termine el mes).
